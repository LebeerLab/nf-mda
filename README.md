# nf-mda

This is a nextflow workflow that wraps the [multidiffabundance](https://github.com/thiesgehrmann/multidiffabundance) tool. To use it, you need both docker and nextflow.

# Running the tool

Adapt `nextflow.config` to your liking (input files, output dir and tools to run) and then run `nextflow main.nf`
The tool makes similar assumptions to mda for the input files.
